# Pressline

**Content that publishes itself.**

An autonomous 8-agent AI pipeline that researches trending topics, writes fact-verified articles, humanizes text below 15% AI detection, and deploys to your live server — three times a day, hands-free.

## Architecture

1. **Trend Researcher** — Scans real search demand, deduplicates against history, synthesizes unique long-tail topics.
2. **SEO Architect** — Selects optimal content format, builds structured blueprint with TOC and FAQ schema.
3. **Master Writer** — Drafts 1,400+ words constrained by verified knowledge base. Every number is real.
4. **Neural Humanizer** — Injects burstiness, strips watermarks, replaces cliches, balances rhythm.
5. **Critic Gate** — Adversarial audit. Blocks if AI score > 15% or math fails reconciliation.
6. **Image Studio** — Generates responsive branded SVG covers. Zero API costs.
7. **Static Builder** — Compiles production HTML with Schema.org, sitemap, RSS.
8. **Live Deployer** — SSH push to production + GitHub commit under your attribution.

## Tech Stack

- Node.js pipeline orchestrator
- Groq + Google Gemini multi-model rotation
- Static HTML5 output (no database)
- GitHub Actions cron scheduler
- SSH/SCP production deployment
